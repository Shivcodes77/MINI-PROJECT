# MINI-PROJECT
drSaab is a simple, open-source health assistant web app built to help users understand their symptoms in everyday language (including English and Hindi) and provides quick health guidance. 
The key features include
1. Simple chat- allows the user to type their symptoms in simple language rather than medical jargon
2. 3 Engine Intelligence- combines machine learning, clinical rules and medical book reading
3. Live Weather Factor Analysis- Analyses health risks based on AQI, humidity, weather and pollution
4. Emergency Flagging- Flags urgent warning flags and provides helpline numbers
